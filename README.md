# Game-Solution

A Godot + Avalonia UI game project built on a fork of [Estragonia](https://github.com/MrJul/Estragonia) (MIT licensed) by [Julien Lebosquain](https://github.com/MrJul) ("MrJul") and its contributors. This fork targets **.NET 8**, [Avalonia UI v11.3.0](https://github.com/AvaloniaUI/Avalonia/releases/tag/11.3.0), and [Godot Engine v4.6](https://github.com/godotengine/godot/releases/tag/4.6-stable).

## Changes from Upstream

- Merged pending upstream PRs, including [sjenning](https://github.com/sjennings)'s Metal backend support for macOS
- Applied ReSharper refactorings and Code Cleanup passes
- Removed unused members

## Getting the Source

A `.zip` archive of `src/` is published under the **Actions** tab on each push to `main` and kept for 30 days. Individual repository subdirectories can also be downloaded as `.zip` archives via [download-directory.github.io](https://download-directory.github.io).
