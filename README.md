# Game-Solution (Estragonia)

This solution uses an upgraded fork of [Estragonia](https://github.com/MrJul/Estragonia) by [Julien Lebosquain](https://github.com/MrJul) ("MrJul"), updated for **.NET 8**. Estragonia is a bridge that enables the use of the [Avalonia v11.3.0 UI framework](https://github.com/AvaloniaUI/Avalonia/releases/tag/11.3.0) within the [Godot v4.6 game engine](https://github.com/godotengine/godot/releases/tag/4.6-stable).

In addition to Vulkan, this fork also supports Apple’s Metal graphics API on macOS, courtesy of [sjennings](https://github.com/sjennings). Most upgrades consist of pull request implementations from the official Estragonia repository, along with ReSharper-driven refactorings, code cleanups, and the removal of unused members.

While the core logic should be reasonably optimized, some spacing and formatting may be inconsistent. Due to the size of the codebase, not every minor stylistic detail has been exhaustively reviewed.
